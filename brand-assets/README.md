## Required final exports

Export these directly from Illustrator after the final artwork is approved:

1. A separate square icon/mark export, if it will be used independently of the full lockup.
2. A separate horizontal wordmark export, if it will be used independently of the full lockup.
3. Matching transparent PNG versions at 2048 px wide or larger.
4. One-color white and one-color indigo versions for embroidery, print, and small-format use.

Keep each export on a tight artboard with no extra white canvas. Preserve the original indigo-and-white treatment; apply the ice-blue and alert-red system in interfaces, not by altering the approved logo artwork.
